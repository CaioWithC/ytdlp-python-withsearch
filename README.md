# ytdlp-python-withsearch
Uma aplicação que baixa videos/audios via yt-dlp em python, com sistema de pesquisa via API do Youtube

# OBRIGATORIOS
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [Deno](https://deno.com/)

### O que é API do Youtube?
A API que a propria Google disponibiliza no Google Cloud, veja mais na [documentação](https://developers.google.com/youtube/v3/docs) do proprio
